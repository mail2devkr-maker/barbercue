Neon reports 21,600 seconds (6 hours) of history retention, no configured snapshot schedule, and only an older 12 October manual snapshot in the snapshot listing; existing October backup branches are not a fresh pre-release recovery point. Railway OAuth configuration redacts the runtime database URL, so its match to this Neon project/branch remains NOT VERIFIED. Both Railway services track `master` with `checkSuites:false`; backend pre-deploy runs `prisma migrate deploy`, and no verified control guarantees backend-first rollout before web. Require a fresh recovery point plus isolated restore evidence, runtime target verification, final migration rehearsal, explicit rollout ordering, and legacy Android contract acceptance before any production release. This PR changes no migration or production resource.
